## ✨ Overview

**AI Study Pack Generator** transforms a topic, learning goal, study duration, and optional notes into a complete personalized study pack.

Instead of using a single AI prompt, the project uses a structured **multi-stage AI workflow** where each stage has a dedicated responsibility and passes its output to the next stage.

The final result can include:

- 📘 Quick topic overview
- 🎯 Learning objectives
- 🧠 Core concepts
- 📝 Exam-focused notes
- 💡 Worked examples and intuition
- 📚 Important terminology
- 🧩 Memory aids
- 🃏 Flashcards
- ❓ Multiple-choice questions
- ✅ Answer explanations
- ✍️ Short-answer questions
- 🧠 Conceptual questions
- 📅 Personalized study plan
- ☑️ Final revision checklist
- 🎯 Self-check statements

## 🧠 Multi-Stage AI Workflow

The application follows this pipeline:

```text
User Input
   │
   ▼
🧭 Planning Agent
   │
   ▼
📚 Content Generation Agent
   │
   ▼
📝 Assessment Agent
   │
   ▼
🔎 Review Agent
   │
   ▼
✨ Refinement Agent
   │
   ▼
🎓 Final Personalized Study Pack
```

### 1. 🧭 Planning Agent

Analyzes the learner's topic, level, available time, goal, and source material.

It creates:

- Learning objectives
- Prerequisites
- Topic decomposition
- Priority concepts
- Time allocation
- Common misconceptions
- Assessment strategy

### 2. 📚 Content Generation Agent

Uses the planner output to generate structured teaching material such as:

- Core concepts
- Exam-focused notes
- Worked examples
- Important terms
- Memory aids

### 3. 📝 Assessment Agent

Builds assessments directly from the generated content:

- Flashcards
- MCQs
- Answer key
- Short questions
- Conceptual questions
- Self-check statements

### 4. 🔎 Review Agent

Performs quality control by checking:

- Factual consistency
- Source alignment
- Missing concepts
- Difficulty level
- Duplicate content
- Assessment/content mismatch
- Exam relevance
- Study-time suitability

### 5. ✨ Refinement Agent

Uses all previous workflow outputs and reviewer feedback to produce the final polished study pack.

---

## 🔄 Context Passing

A shared workflow context allows each stage to use information generated by earlier stages.

```text
ctx.plan
   ↓
ctx.content
   ↓
ctx.assessment
   ↓
ctx.review
   ↓
ctx.final_pack
```

This makes the workflow easier to debug, extend, and improve compared with a single large prompt.

## 🛡️ Reliability & Error Handling

The workflow includes:

- Automatic retries for failed AI stages
- Stage status tracking
- Graceful fallback content
- Error collection
- Best-available output if final refinement fails

Workflow states are shown in Streamlit as:

- ⚪ Pending
- 🟡 Running
- 🟢 Success
- 🟠 Fallback
- 🔴 Failed

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sabirprogrammer/study_pack.git
cd study_pack
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add your SenseNova API key

Set an environment variable named:

```text
SENSENOVA_API_KEY
```

Or enter the key through the Streamlit sidebar when running locally.

### 4. Start the application

```bash
streamlit run app.py
```
